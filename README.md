# ملاحظاتي · My Notes

منصة ملاحظات شخصية وآمنة لكل مستخدم، بواجهة عربية كاملة **RTL** بتصميم عصري على نمط الشركات العالمية.

- ✅ تسجيل/دخول — وعزل صارم لبيانات كل مستخدم عن الآخرين
- ✅ تصنيفات وألوان · تثبيت · مفضلة · أرشفة · سلة مهملات (30 يومًا)
- ✅ بحث فوري · ترتيب · عرض شبكي/قائمة
- ✅ حفظ تلقائي أثناء الكتابة · تصدير JSON/Markdown
- ✅ مظهر فاتح وداكن · تصميم متجاوب بالكامل · دعم RTL كامل

المشروع يتضمن **نسختين** للاستضافة:

| | نسخة GitHub Pages (الأساسية) | نسخة الخادم (بديلة) |
| --- | --- | --- |
| الاستضافة | GitHub Pages (مجاني، بلا خادم) | أي منصة Node (Render/… ) |
| قاعدة البيانات | **مستودع GitHub الخاص بك** | SQLite مدمجة |
| الدخول | رمز وصول شخصي (PAT) يُحفظ في متصفحك | بريد وكلمة مرور مع Scrypt |
| العزل | يفرضه GitHub نفسه (مستودع لكل مستخدم) | شرط `user_id` في كل استعلام |

## نسخة GitHub Pages — كيف تعمل

لا تستطيع Pages تشغيل خادم، لذا يتحول المتصفح نفسه إلى العميل الكامل لـ
**GitHub Contents API**:

1. **الدخول برمز PAT**: تنشئ رمز وصول خاصًا (`ghp_…` أو `github_pat_…`)
   من GitHub، ويُخزَّن **في متصفحك فقط** (`sessionStorage دائمًا + localStorage
   عند «تذكرني») — لا يُرسل إلى أي خادم خارجي.
2. **مستودع البيانات**: عند أول دخول يُنشأ تلقائيًا مستودع خاص باسم
   `mynotes-data` في حسابك (خاص افتراضيًا).
3. **ملف واحد**: كل بياناتك (الملف الشخصي والتصنيفات والملاحظات) في ملف
   `notes.json` واحد، يُقرأ ويُكتب عبر Contents API مع إعادة محاولة تلقائية
   عند تعارض `sha` (تعديل من تبويب آخر).
4. **العزل**: كل مستخدم يقرأ ويكتب في مستودعه هو — عزل فعلي يفرضه GitHub،
   لا يمكن اختراقه من جهة الواجهة.
5. **الحفظ المؤجّل**: الكتابة لا ترفع كل حرف؛ الحفظ ينتظر توقفك 1.2 ثانية ثم
   يرفع الملف مرة واحدة (محرّر النص: 0.9 ثانية)، مع رفع إجباري قبل إغلاق
   التبويب إذا كان هناك ما لم يُرفع بعد.

### الاستخدام

1. افتح الموقع على GitHub Pages (سير `pages.yml` ينشره مع كل دفع):
   <https://mariamemran1810-cloud.github.io/my-notes/>
2. أنشئ رمزًا: GitHub → **Settings → Developer settings → Personal access tokens
   → Fine-grained tokens → Generate new token** (أو **Tokens (classic)**).
3. الصق الرمز في صفحة الدخول. إن لم يكن لديك مستودع `mynotes-data` سيُنشأ
   تلقائيًا بأذن `repo` (أو `Contents: read/write` في الرمز المُفصّل).

> ⚠️ الرمز يمنح صلاحية لمستودعات حسابك — لا تشاركه، ولا تُدخله في جهاز غير
> موثوق. «تسجيل الخروج» يمسحه من المتصفح فقط (إلغاءه من GitHub: Settings →
> Developer settings → Tokens).

## التشغيل والبناء محليًا

```bash
cd my-notes
npm install
npm run build:pages     # بناء نسخة Pages في dist-pages/
```

| الأمر | الوظيفة |
| --- | --- |
| `npm run build:pages` | بناء نسخة Pages الكاملة (هبوط + دخول + لوحة) |
| `node scripts/verify-dist.js` | فحص مخرجات البناء (17 فحصًا) — يعمل تلقائيًا في CI |
| `node scripts/preview.js` | معاينة ثابتة على <http://127.0.0.1:4173> |
| `node test/mock-github.js` | محاكي GitHub API على <http://127.0.0.1:4174> (للاختبار فقط) |
| `npm start` | تشغيل **نسخة الخادم** على <http://localhost:3000> |
| `npm test` | اختبارات نسخة الخادم (96 اختبارًا) |

لاختبار نسخة Pages محليًا ضد المحاكي: افتح
`http://127.0.0.1:4173/login.html?api=http://127.0.0.1:4174` ثم سجّل الدخول
بأي رمز يبدأ بـ `gp`/`ghp_`. المُحاكي يحفظ الحالة في الذاكرة أثناء الجلسة.
في الإنتاج لا يوجد `?api=` — يُستخدم `https://api.github.com` تلقائيًا.

متطلب: Node.js ‏22.5 أو أحدث (لتوافر الوحدة المدمجة `node:sqlite` في نسخة الخادم).

## النشر

### 1) GitHub Pages (النسخة الأساسية)

1. على صفحة المستودع: **Settings → Pages → Build and deployment →
   Source: GitHub Actions**.
2. سيقوم سير `.github/workflows/pages.yml` بالبناء (من `public/**` +
   `pages-app/**`) وفحص المخرجات (`verify-dist.js`) ثم النشر تلقائيًا مع كل
   دفع إلى `main`.
3. الموقع يعمل بعلاقة `<اسم-المستودع>.github.io/<المستودع>/` — بلا متغيّرات
   بيئية ولا روابط خارجية.

### 2) نسخة الخادم على Render (بديلة)

1. <https://dashboard.render.com> → **New + → Blueprint** → اختر المستودع.
2. يقرأ Render ملف `render.yaml` تلقائيًا → **Apply**.
3. حفظ البيانات الدائم: `Settings → Disk → Add Disk` ثم اضبط
   `DB_PATH=/var/data/mynotes.db`.

## الأمان

### نسخة Pages

| البند | التنفيذ |
| --- | --- |
| رمز الدخول | PAT يُخزَّن في متصفح المستخدم فقط، لا يُرسل لطرف ثالث |
| العزل | مستودع بيانات مستقل لكل مستخدم يفرضه GitHub |
| الخصوصية | المستودع يُنشأ خاصًا افتراضيًا |
| الحماية من فقد الكتابة | رفع مؤجّل + إعادة محاولة عند تعارض `sha` + رفع قبل إغلاق التبويب |
| الشبكات | كل النصوص العربية تُرمَّز Base64 بترميز UTF-8 آمن |

### نسخة الخادم

| البند | التنفيذ |
| --- | --- |
| كلمات المرور | Scrypt ‏(N=16384) + ملح عشوائي 16 بايت |
| الجلسات | كوكى `HttpOnly` + `SameSite=Lax` + رمز CSRF لكل جلسة |
| عزل البيانات | كل استعلام مقيد بـ `user_id = المستخدم الحالي` |
| CSRF | فحص `Origin` + رأس `X-CSRF-Token` على كل الطلبات غير الـ GET |
| Brute force | 10 محاولات دخول لكل بريد/IP كل 10 دقائق |
| الترويسات | `X-Frame-Options`, `nosniff`, `Referrer-Policy`, HSTS في الإنتاج |

## واجهة API (نسخة الخادم)

| الطريقة | المسار | الوصف |
| --- | --- | --- |
| `POST` | `/api/auth/register` | إنشاء حساب |
| `POST` | `/api/auth/login` | تسجيل الدخول |
| `POST` | `/api/auth/logout` | تسجيل الخروج |
| `GET` | `/api/auth/me` | المستخدم الحالي + الإحصاءات + رمز CSRF |
| `PATCH` | `/api/auth/profile` | تعديل الاسم/البريد/كلمة المرور |
| `GET` | `/api/notes` | قائمة الملاحظات (`scope`, `q`, `category`, `sort`) |
| `POST` | `/api/notes` | إنشاء ملاحظة |
| `GET` | `/api/notes/:id` | ملاحظة واحدة |
| `PATCH` | `/api/notes/:id` | تعديل/تثبيت/مفضلة/أرشفة |
| `DELETE` | `/api/notes/:id` | نقل إلى السلة (`?permanent=1` للحذف النهائي) |
| `POST` | `/api/notes/:id/restore` | استعادة من السلة |
| `POST` | `/api/notes/empty-trash` | تفريغ السلة |
| `GET/POST/PATCH/DELETE` | `/api/categories…` | إدارة التصنيفات |
| `GET` | `/api/export?format=json\|md` | تصدير الملاحظات |
