نسخة Pages تخزّن ملاحظاتك في مستودع GitHub خاص بك — لا يراه أحد سواك، ولا يوجد خادم وسيط.

  • مستودع خاص يُنشأ تلقائيًا لك
  • رمزك يبقى في متصفحك ولا يُرسل لأحد
  • سجل كامل لكل تعديل في Git

تسجيل الدخول

ألصق رمز GitHub الشخصي (PAT) للوصول إلى ملاحظاتك

كيف أنشئ رمز الوصول الشخصي؟ (خطوات)
  1. افتح صفحة الرموز: github.com/settings/tokens
  2. اضغط Generate new token (classic)
  3. حدّد صلاحية repo فقط (تكفي لإنشاء مستودع خاص وحفظ ملفاته)
  4. اضغط Generate token وانسخ الرمز فورًا (لن تراه مرة أخرى)
  5. ألصقه هنا — سيُنشأ لك مستودع خاص باسم mynotes-data تلقائيًا

الرمز يُخزَّن في متصفحك فقط ولا يُرسل إلى أي خادم. إن شاركت جهازك، اترك «تذكّرني» غير مفعّل — يُمسح الرمز عند إغلاق التبويب.

هذه النسخة تعمل على GitHub Pages — لا يوجد خادم وسيط بينك وبين بياناتك.
