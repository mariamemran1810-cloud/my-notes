كل ما تحتاجه لتنظيم أفكارك

أدوات بسيطة وفعّالة، بدون تعقيد أو إعلانات مزعجة.

إنشاء وتعديل فوري

اكتب عنوانًا ونصًا، اختر لونًا وتصنيفًا، واحفظ خلال ثانية مع حفظ تلقائي أثناء الكتابة.

بحث وتصفية ذكية

ابحث داخل العناوين والنصوص فورًا، وصفّي حسب التصنيف أو المثبّت أو المفضلة.

تثبيت وأرشفة

ثبّت المهم في الأعلى، أرشف ما انتهى، وأنقل ما لا تحتاجه إلى سلة مهملات قابلة للاستعادة.

تصنيفات ملوّنة

أنشئ تصنيفاتك الخاصة (عمل، شخصية، أفكار…) وأدرها بلوان مميزة تُسهّل الوصول السريع.

تصدير بصيغتين

نزّل كل ملاحظاتك كملف JSON أو مستند Markdown في أي وقت — بياناتك ملكك.

سرعة وأداء

واجهة خفيفة بدون إطارات ثقيلة، تعمل بسلاسة على الهاتف والكمبيوتر ولوحة المفاتيح.

الخصوصية أولًا

ملاحظاتك لا يراها أحد غيرك

صُمّمت المنصة بحيث تكون بيانات كل مستخدم معزولة تمامًا على مستوى قاعدة البيانات نفسها، وليس مجرد إخفاء في الواجهة.

  • عزل على مستوى الاستعلام — كل عملية قراءة أو تعديل أو حذف مقيّدة بمعرّف صاحب الجلسة.
  • كلمات مرور مشفّرة — خوارزمية Scrypt مع ملح عشوائي، ولا تُخزَّن كلمة مرورك كنص أبدًا.
  • جلسات HttpOnly — الكوكي غير قابل للقراءة من الجافاسكريبت، مع رمز CSRF لكل طلب.
  • حد لمحاولات الدخول — يُبطئ أي محاولة تخمين لكلمة المرور تلقائيًا.

إجابات سريعة

هل يستطيع مستخدم آخر رؤية ملاحظاتي؟

لا. كل استعلام في الخادم مقيّد بمعرّف حسابك، ولا يوجد أي مسار يتيح الوصول لملاحظات مستخدم آخر حتى لو عرف رقم الملاحظة.

كيف تُحفظ كلمة المرور؟

تُشفَّر بخوارزمية Scrypt مع ملح عشوائي لكل مستخدم، ولا تُخزَّن نصًا صريحًا في قاعدة البيانات إطلاقًا.

هل أستطيع تصدير ملاحظاتي؟

نعم، من داخل التطبيق يمكنك تنزيل كل ملاحظاتك بصيغة JSON أو Markdown في أي وقت.

ماذا يحدث إذا حذفت ملاحظة بالخطأ؟

تنتقل إلى سلة المهملات وتبقى 30 يومًا، ويمكنك استعادتها بضغطة واحدة أو حذفها نهائيًا.

هل الخدمة مجانية؟

نعم، إنشاء الحساب والمزايا الأساسية مجانية بالكامل دون بطاقة ائتمان.
